Installing takes a minute

  1. 1

    Run the installer

    Open BaracutReader-Setup-1.6.0.exe from your Downloads folder.

  2. 2

    Choose your options

    Add Baracut Reader to Open with for PDF files and, if you like, a desktop shortcut. Then choose Install.

  3. 3

    Start editing

    Open Baracut Reader from the Start menu, or right-click a PDF and choose Open with.

Windows may show a SmartScreen message

This version isn't digitally signed yet, so Windows may say it doesn't recognize the app. If you downloaded the installer from this page and its checksum below matches, choose More info → Run anyway.

Verify your download

To confirm the installer arrived intact and unmodified, compare its SHA-256 checksum with this one.

1f436d431bfa96a1d79ffccf0c78f630cd55ff66e9ea7f3163d58fbd757c673f

In PowerShell, in the folder you downloaded it to:

Get-FileHash .\BaracutReader-Setup-1.6.0.exe -Algorithm SHA256

The update system inside the app checks this automatically before installing any update.
