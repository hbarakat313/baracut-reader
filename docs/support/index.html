Installing

  1. Download the installer from the download page.
  2. Open it from your Downloads folder. If Windows SmartScreen says it doesn't recognize the app, check the checksum on the download page, then choose More info → Run anyway.
  3. Choose your options and Install. No administrator permission is needed; Baracut Reader installs for your Windows account.
  4. Open it from the Start menu.

To make Baracut Reader your default PDF app, right-click any PDF, choose Open with → Choose another app, pick Baracut Reader and select Always. Windows lets only you make that choice. In the app, More options → Set as default PDF app takes you there.

Updating

Baracut Reader checks for a newer version about once a day and shows a small notice when one is available. Choose Update (or open More options → Check for updates) to download it. You can keep working while it downloads. When it's ready:

  • Install and restart closes the app, installs the update and opens the app again. You're asked to save unsaved changes first.
  • Install when I close the app installs it quietly after you close Baracut Reader.
  • Later leaves everything as it is; the update stays ready.

You can also install a newer version over an older one by running its installer from the website. Your settings and documents are kept.

Uninstalling

Open Settings → Apps → Installed apps, find Baracut Reader, and choose Uninstall. The program, its shortcuts, its Open with entry and downloaded updates are removed. Your PDFs are never touched. Settings and logs remain in %LOCALAPPDATA%\Baracut Reader; delete that folder to remove them too.

Opening and saving PDFs

  • A PDF won't open. Files that are damaged, or use features Windows can't display, are refused with an explanation, and nothing changes. Try opening the file in another PDF reader to check it isn't damaged.
  • A PDF asks for a password. Enter the password it was protected with. Baracut Reader can't recover a forgotten password; ask whoever protected the PDF for it. PDFs protected with certificates can't be opened.
  • A line of text can't be edited. Scanned pages, rotated or vertical text and text drawn as shapes can't be changed. You can still highlight it or add text over it.
  • Saving fails. The original file is left exactly as it was and your edits stay open. Check that the folder is writable and the file isn't open in another app, or use Save as to choose another place.
  • Another reader doesn't show my edits as editable. That's expected: other readers show the finished pages. Your additions stay editable when you reopen the file in Baracut Reader.

If the app doesn't start

  • If you just updated, wait a moment: while the update finishes, the app shows Finishing the update… and then opens.
  • Restart your computer and try again.
  • Reinstall the current version from the download page. Your documents and settings are kept.
  • Diagnostic details are written to %LOCALAPPDATA%\Baracut Reader\Logs. They never leave your computer unless you send them.

Download problems

  • If your browser blocks or warns about the download, make sure you started it from this website, then keep the file.
  • If the download stops, try again; a partial file can't be installed.
  • Compare the file's SHA-256 checksum with the one on the download page. If they differ, delete the file and download it again.

Update problems

  • “We couldn't check for updates.” Your computer seems to be offline. Connect and choose Try again.
  • “The update service is temporarily unavailable.” The service couldn't be reached. Your version keeps working; try again later.
  • “The update couldn't be downloaded.” The connection dropped. Nothing was changed; choose Try again.
  • “The downloaded update couldn't be verified.” The file didn't match the signed release information, so it was deleted and nothing was installed. Choose Download again; if it keeps happening, download the installer from the website.
  • “Close other Baracut Reader windows first.” Save your work in the other window and close it, then choose Install and restart again.
  • The update wasn't installed. Your current version is still installed and works. Choose Check for updates to try again, or run the newest installer from the website.

Where things are kept

Program
%LOCALAPPDATA%\Programs\Baracut Reader
Settings
%LOCALAPPDATA%\Baracut Reader\settings.json
Diagnostic logs
%LOCALAPPDATA%\Baracut Reader\Logs
Downloaded updates
%LOCALAPPDATA%\Baracut Reader\Updates, removed after installing
Your documents
Wherever you save them
