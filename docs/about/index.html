About Baracut Reader

Baracut Reader is a PDF editor for Windows, built for the everyday edits people make to documents they already have.

What it's for

Most PDF work is small: fix a date, add a note, highlight the part that matters, put pages in the right order. Baracut Reader makes those edits directly in the document and saves an ordinary PDF that anyone can open.

How it's made

  • The document comes first. Quiet tools around a page that stays in focus.
  • Your files stay yours. Everything happens on your computer; nothing is uploaded.
  • Honest about limits. When something can't be edited, the app says so instead of guessing.
  • Careful with your work. Saves never leave a half-written file, and updates never close unsaved work.
  • Accessible. Keyboard support throughout, screen-reader labels, and light, dark and high contrast themes.

Platform

Baracut Reader is a native Windows desktop app for Windows 10 (version 22H2) or Windows 11 on 64-bit PCs. It's built with .NET and Windows Presentation Foundation, and it uses the PDF rendering built into Windows. New features arrive through the built-in updater; see the changelog for what each version changed and the features page for what's planned.
